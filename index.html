About this service

One bot, many users.

You do not need to create your own bot. The administrator owns one Telegram bot for the whole service, while each user starts a private subscription with that same bot. Your chat ID is used only to deliver your alerts; it is not shown on the website.

The runner uses read-only availability checks. You still complete identification, personal-data entry, payment if applicable, and booking directly on Migri.
